# 📝 Task Manager - React + TypeScript

Aplicación web para la gestión de tareas desarrollada con **React y TypeScript**.

Este proyecto fue realizado como parte de mi proceso de aprendizaje de TypeScript, con el objetivo de aplicar conceptos como tipado, interfaces, estados, eventos y manipulación de datos dentro de una aplicación React.

## 🚀 Funcionalidades

La aplicación permite realizar las operaciones principales de un CRUD:

- ➕ Crear nuevas tareas.
- 📋 Visualizar las tareas registradas.
- ✏️ Editar una tarea existente.
- 🗑️ Eliminar tareas.
- ✅ Cambiar el estado entre `Pendiente` y `Completada`.
- 💾 Guardar las tareas utilizando `localStorage`.
- 🔢 Mostrar la cantidad total de tareas.

## 💻 Conceptos aplicados

Durante el desarrollo del proyecto se aplicaron diferentes conceptos de React y TypeScript:

- Tipado de datos.
- Definición del tipo `Tarea`.
- Arrays tipados.
- Funciones con parámetros tipados.
- `useState`.
- `useEffect`.
- Eventos de React.
- Renderizado de listas.
- Renderizado condicional.
- Métodos `map` y `filter`.
- Persistencia de información con `localStorage`.

## ⚙️ Instalación

Clona el repositorio:

```bash
git clone https://github.com/Piero2023/task-manager-typescript.git
```

Ingresa al proyecto:

```bash
cd task-manager-typescript
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el proyecto:

```bash
npm run dev
```

Después abre en el navegador la dirección que muestra Vite, normalmente:

```text
http://localhost:5173
```
